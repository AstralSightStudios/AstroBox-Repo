V2.1.0 是 2.0有史以来最大的更新，这是一个在方方面面都重新斟酌的全新版本，我们希望在这个版本中为你带来更加完整、精致、优秀的穿戴设备第三方体验，无论是视觉还是用户体验上，都能让你眼前一亮。

iOS 版现已上架 App Store，若你在使用 iOS/iPadOS，请前往 App Store 搜索 AstroBox 下载并更新。

## 新增功能

- 账号体系重构：新增应用内登录、第三方账号（Github / 爱发电 / 米坛 / Apple）绑定与解绑，支持显示名称修改、Apple 原生登录，未登录时引导登录以解锁付费资源下载。
- 浅色模式与主题系统：全面新增浅色模式并支持跟随系统自动切换；增加基于 MD3 配色的全新主题系统，可自选主题色或导入图片生成配色。
- 表盘壁纸系统：新增多表盘壁纸支持、表盘壁纸生成器、表盘壁纸记录持久化，统一壁纸编辑页与表盘编辑交互。
- 测速重构：测速改为真实图片下载耗时而非 HEAD 探测，按五级色阶分级配色；打开时自动选中最佳线路并沿用上次 CDN，可后台自动静默切换。
- 小米账号联动：登录小米账号后自动导入设备；支持启动时自动同步、AuthKey 自动覆盖；开启固件共享计划后自动检查并上报所有小米导入设备的版本。
- 固件增量包识别：支持识别小米增量固件包。
- 资源类型扩展：新增模块类型（canopus）资源支持、捆绑资源（manifest）支持、官方源图标展示。
- 设备页小组件系统：全新小组件框架，多尺寸可拖动、支持导入导出配置。
- 新增许可协议页面、内容最大宽度设置、窗口大小位置记忆（桌面端）、ServerLink API 控制开关、文件关联图标补全（mwz 等）。
- 评论放开：有 AB 账号即可评论，未登录时有引导提示。
- 新增韩、法、德、西、意 5 种语言，全部语言包重新审计补全。

## 体验与界面
- 探索页、全部资源页全面重构：新顶部区域、可滑动预览图卡片、统一加载占位、下拉刷新、离线提示、文章可关联单个或多个资源，支持自定义栏目。。
- 插件市场与全部资源页新增顶部悬浮搜索框，搜索时展示对应插件图标。
- 重做表盘编辑页面与移动端操作面板，表盘 ID 显示与自动重试。
- 重做队列卡片：报错信息优化、「前往文档」跳转、重连按钮、断连清空队列与断点续传。
- 重做 OOBE 初始化流程并新增个性化设置步骤；重做个人主页（含自定义 HTML 板块 iframe API、骨架屏、失败重试）。
- 全新 dialog 统一组件、drawer 统一把手、导航栏经典/极简样式切换、底部 Tab 紧凑模式与跑马灯。
- 深浅主题切换动效（View Transitions 淡化）；修复系统字体缩放导致的布局异常（锁定根字号）。
- 资源详情页、插件详情页重做；支持宽屏下双行布局；赞助页全面优化（含 HyperOS 背景、触控滑动）。

## 问题修复
- 修复 iOS 跟随系统深浅色每次打开都是浅色的问题；修复 macOS 深浅色切换红绿灯移位（常驻 watchdog 校准）。
- 修复插件打开导致全局锁死深色、热重载后 UI 刷新、加载失败页卸载放行等问题。
- 修复多资源同时安装报错、切换 CDN 后刷新初始化顺序、设备页编辑按钮无响应、键盘弹出后页面可滑动等大量交互问题。
- 修复文件无法正常选取问题
- 修复 Chromium 模糊、WebKit 标题阴影裁剪、宽屏 dialog 按钮布局等跨平台细节。
- 修复同名表盘跨设备编辑缓存互相串用、队列终态显示、iOS 图标实际生效（AstroBox V2 图标）。
